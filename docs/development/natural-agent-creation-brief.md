# 自然语言创建 Agent 与打开私聊

2026-10-05 用户在个人助理中明确要求创建区块链项目 Agent，实际回复只给了人设。本批补齐“明确创建请求 → 生成档案 → 真实联系人 / 私聊 → 当前页面打开”的闭环。

## 实施范围

- 仅本人个人助理中的本条明确创建命令可以进入创建流程；不把普通对话、引用、否定、转述、历史记录或模型自行建议当成创建授权。用户按发送提出明确命令即为此次创建意图，无需重复填写或确认表单。
- 模型生成名称、介绍、能力和性格四项档案；信息不足可澄清。模型只提出数据，后台严格校验并沿现有联系人与直接会话服务保存。不会赋予联网 / PDF / SDK 文件读取 / 运行工具权限。
- 同一请求与模型结果保存通过现有幂等和 worker fence；本人完全相同的 specialist 档案可复用。联系人、直接会话、真实回执与创建结果同时成功，失败不能留下孤立联系人或伪造完成宣言。
- 当前发送页面在同账号 / 世代 / 路由 / 会话仍有效时，对本条成功结果只自动打开一次；主动离开、另选会话、卸载或切账号取消自动导航。历史回执提供手动打开按钮。创建成功但 IM 未就绪保留联系人，重试只打开已有私聊。
- 模型选择、输入与输出合计4000 Token / 90秒预算、权限、取消和输入变化守卫保留。创建档案只使用本条完整明确请求；普通日常聊天保持原授权历史与记忆。不会复制助理或旧任务的私有记忆给新Agent。
