# 科研能力中心与资料素材库

2026-10-10，Windows 0.10.0，contract 0.24.0 / chat 1.12.0，migration 022。本批完成第一阶段；安装包、云端版本与实际检查以[当前状态](../current-state.md)为准。

## 用户路径

1. 广场进入科研能力中心，查看发现能力、课题组能力、我的 Agent。按文献阅读、写作、研究设计、图表、数据代码和课题协作分类。列表来自真实可见档案，空列表与读取失败分别显示。
2. 六份配置可添加为私人 Agent：文献阅读、论文改稿、研究方案、图表构思、数据复现讨论、组会汇报。它们是可编辑文字配置；添加不会安装绘图、执行或联网工具。
3. 工作台 → 资料与素材库，新建集合，选择仅自己、任务授权、课题组或公开范围。导入来源并补充题名、作者、年份、DOI、标签与备注。
4. 我的 Agent 详情选择获准集合并保存绑定。本人和本地私人 Agent 的日常聊天中，后台按当前问题检索；回答下方可以展开实际提供给模型的来源片段。
5. 我的技能导入完整文件夹、ZIP 或固定 GitHub 修订，浏览本机素材、参考文件、脚本源码，另存原件，或明确选择一个原件导入指定资料集合。

## 数据与授权

集合、不可变文件版本、提取页、Agent 绑定分别存储。原件记录 SHA256，替换版本保留旧原件；撤回保留状态，不能继续检索。task_scoped 使用已有真实任务访问规则。公开 Agent 档案不会公开绑定或资料。

检索先按当前账号授权过滤，再排序与限制结果。请求保存绑定、集合版本，调用前、流式输出期间和提交结果前重新检查；撤回、改绑或版本变化会拦截过期输出。失效资料产生的旧对话不再进入后续模型上下文，已有聊天记录保留。

私人资料不会自动传入群聊、他人 Agent、外部 Endpoint、Agent 创建或协作规划。绑定不授予新权限，来源正文不能授权执行动作。

## 阅读范围与限制

- 单份来源最多 10 MiB；PDF、TXT、Markdown、CSV 提取文字。图片、代码、ZIP 等保留原件并显示仅原件，不称已经识读。
- 第一阶段使用关键词相关度检索、中文分词。普通无匹配返回无匹配；明确概览请求允许有界的页面开头选段。
- 一次上下文最多 10,000 字符，进一步受该次已保存的聊天预算限制。保留精确版本、页码、字符范围，不把选段说成全文阅读。
- `[R1]` 等来源回执表示实际提供给模型的内容，不代表对所有主张或引用语义的独立核验。展开按当前权限读取原文。
- 原件视觉理解、向量检索、参考图自动选择、脚本沙箱、真实绘图和科研评估仍需后续实现；六份模板不代表这些能力上线。

## 本机 Skill 素材

说明文本与完整包分开。预览取消不安装；说明保存成功后提交本机原件，原件提交失败可重试。管理库按服务地址、账号、Skill 和修订分区；这不是操作系统加密，也不替代服务器授权。

每包最多 100 MiB 展开内容，原 ZIP 最多 32 MiB；管理库最多 1 GiB / 200 修订。拒绝路径穿越、符号链接、大小写重名等歧义，读取核对哈希。脚本只显示源码，不运行。本机原件不随文字授权复制给他人。
