# 可添加的科研聊天 Agent

2026-10-05 用户指出没有可直接使用的成品 Agent。本批补三个入口：文献阅读助手、论文修改助手、研究方案助手。

## 当前范围

- 通讯录直接展示助手、适用输入及边界。选择并确认后保存真实的本人 `specialist` 联系人档案，沿现有直接会话与 IM bridge 打开私聊，不自动发送消息。
- 文献阅读仅分析用户粘贴的摘要或正文；论文修改保留事实与数字；研究方案输出尚待验证的建议。不声称联网检索、自动读 PDF、执行实验或自主完成科研工作。
- 能力、介绍、性格进入既有日常聊天模型上下文；使用发送者本人模型及当前权限下的记忆。原自定义 Agent、资料编辑、获准记忆和好友同意机制保留。
- 本人已有 `specialist` 的名称、介绍、能力、性格四字段完全一致时复用。它不是全局唯一模板关系；用户改过的档案仍为稳定联系人，可从联系人资料继续聊天。
- 创建完成立即保存联系人 ID。随后刷新或 IM 打开失败显示已添加状态，再试只打开已有联系人。旧账号、离开的路由、关闭重开后迟响应不能导航或写回。
