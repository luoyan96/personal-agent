# 桌面记忆体验

AcceptCat 0.8.6 本地候选。针对记忆页长期被说明、设置和新增表单占据的反馈，重排阅读与管理顺序。只修改桌面客户端，复用已有个人记忆与提醒接口，无新模型、契约或数据库迁移。

## 使用顺序

- 从现有“我的助理 / 关于我”入口进入，默认打开“记忆”，另一页保留“任务与提醒”。
- 上方“我对你的了解”引用最近两条**已确认**记忆正文，显示实际更新时间。没有记忆时邀请记录第一件事，不编造人物画像。预览较长内容最多显示两行，“查看全部”回到完整条目。
- 右侧“通用偏好 / 主题记忆”显示真实数量，点击按使用范围筛选。下面可查看已记住、待确认或已移除记录，并搜索当前列表。候选与历史分页时明确标成“搜索本页记忆”。
- “记住一件事”打开独立编辑窗口；修改、来源详情和移除在条目上。修改候选明确标为“保存并确认”，避免把即将生效的操作当作普通草稿保存。
- 设置单独打开：候选提议开关、默认时区及安静时段。主页面只保留简短的使用范围提示，详细规则从链接查看。

## 数据与生命周期

`PersonalMemoryPanel` 使用完整的已确认记录读取（当前API上限50）作为摘要、数量、范围筛选的共同来源；候选和撤回列表单独分页。没有第二套假数据或本地画像。保存、纠正、确认与移除仍使用 `expectedVersion`。网络错误保留编辑内容，成功回执后刷新列表；读取失败提供重试，不冒充空列表。

本人记忆仅用于本人持有的本站Agent私聊；候选确认前不进入摘要和后续回答。群聊、他人的Agent、接入的外部Agent不读取这份个人记忆。换账号、联系人、页面或关闭面板时按既有个人操作作用域失效，并关闭本页拥有的说明和确认窗口。单Agent私有记忆的既有管理不在本批修改。

设置依然是服务端真实策略；这次不增加自主性格学习、健康数据、自动生成日记或永久无限上下文。摘要为已确认内容的可读预览，不声称已经具备完整人格分析。

## 设计对照

用户提供的移动参考用于阅读顺序与柔和视觉，采用桌面布局。先生成概念，再与实际渲染对照：

| 项目 | 实际实现与有意差别 |
| --- | --- |
| 布局 | 顶部两页导航，摘要与两个分类并排，下方开放式条目；小窗口仅内容区滚动，导航与关闭按钮始终可见；保留当前桌面弹窗入口 |
| 层级 | 32px页面标题、23px摘要标题、16px正文；具体字形使用Windows字体 |
| 颜色 | 淡蓝渐变摘要、鼠尾草绿操作、白色正文，避免整页蓝色管理表单 |
| 留白 | 32px弹窗内边距、圆角摘要、细分隔线；新增输入仅在编辑窗口出现 |
| 图标 | 通用偏好用设置图标，主题和条目用打开的书，来源/删除归入更多菜单 |
| 内容 | 数量、日期及主题来自真实API；示例概念中的固定数量与人物叙述不复制进产品 |
