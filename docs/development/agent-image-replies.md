# 发给 Agent 的图片：识字、回复与恢复

AcceptCat Windows 0.8.2 客户端修复，固定软件源码 `3f0c666c12baec996bfe1b6201dd690d0ae5574c`。基于0.8.1图片粘贴版本；没有后端、契约、worker、数据库或原生OCR实现变化。

## 原因和使用

旧图片发送只完成OpenIM消息，不进入文档阅读/Agent请求。0.8.2在原SDK发送成功后，用用户选取的完整原图进行Windows本机OCR，再把完整识别文字交给既有`agentFileMessage`接口。模型请求使用当前账号和模型配置；不使用缩略图，也不将长图识别文字裁成普通聊天长度。

- 新图片：本站Agent单独聊天里粘贴、选取或拖入图片，点击“发送图片”；送达后自动识字并请求回复，处理中显示实际状态。
- 已发送的图片：点击图片下方“识别并回复”，只取回原图，不重复发送IM图片。无法取回原图时可点击“从本机选择识别”，选择同一附件对应的原图，大小不匹配会拒绝。
- 无文字、OCR失败、取回失败和服务失败有明确提示与恢复入口。服务重试保留准备好的文字请求；同一图片使用稳定SDK编号生成幂等键和文字附件名，避免本机文件改名导致重放冲突。
- 回复仍由真实API/worker与规范消息回执发布；识别成功不代表模型已经回复。成功后移除临时输入区提示；历史消息保留阅读说明。
- 长图聊天预览最高280px；点击可查看原图。

## 边界

只对当前账号、配对IM身份、可聊天的本站Agent、本人发送且成功送达的单聊图片自动处理。真人、群聊和外部运行时保持普通图片消息，不自动转发给模型。切换账号/联系人/页面会撤销未完成操作、取消原生OCR并屏蔽旧结果；已明确提交的规范API请求仍属于原授权会话。

原生OCR沿用0.8.1字节/像素/时间和Windows语言包限制；在本机执行固定程序，不执行图中指令。旧图片下载只接受既有受信文件来源、原图地址、受限大小与无跳转路径。完整文字作为不可信文档数据进入既有文件接口，权限和文件预算仍由服务器检查。

这是**图片文字处理**，尚不是完整多模态视觉理解：不能据此理解纯图表、物体、布局或无字照片。中文复杂字、模糊截图、数字和专名需要校对。生产IM、实际模型供应商、用户原图及旧安装覆盖升级未在此批实测。
