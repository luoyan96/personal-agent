# 私人技能：安装、授权与聊天

Windows 0.6.0 的入口为工作台 → 我的技能。可选择含 SKILL.md 的文件夹、技能 ZIP，或 GitHub 仓库根地址。GitHub 导入先显示根目录的包选项，选择后固定到实际提交 SHA；不会猜测哪个 ZIP 是最新版本。

## 已实现

- 安装前检查名称、简介、版本、完整说明、参考文件与执行依赖；确认后保存到本人账号空间，默认私人、启用、不绑定、不授权。
- 将技能绑定到自己的站内 Agent；聊天时明确选择技能、所需参考文字和本次仅文字执行的确认。
- 完整控制说明、参考目录索引和最多八个选中参考文字进入模型上下文。普通消息不附带私人方法源码。单次技能聊天总预算上限 128000 tokens / 90 秒，超限明确失败，不静默截断。
- 公开名称和介绍、允许好友调用、允许好友复制文字源码分别控制。调用者使用自己的 Agent / 模型配置；接受关系、当前权限、版本和绑定在执行前后重新核对。撤权或换版会使旧结果失效。
- 新版本作为不可变修订保存，可切回历史修订；启停、版本变化和授权变化均更新权限代数。显示本人实际调用记录，“回复完成”只表示模型文字完成。

调用授权不提供源码接口，但模型输出仍可能包含方法内容，不能承诺不可复制。源码复制创建对方的私人副本，撤销后不能远程删除已有副本。私人技能存储在服务器的本人空间，调用内容会发给本人选择的模型供应商；“私人”不表示只存在本机。

## 当前运行边界

执行器仅使用完整文字流程和获准附件文本，未提供任意 Python / shell / 浏览器、文件写入、图片生成、参考图输入或 checkpoint 运行环境。包内脚本和二进制素材仅计数和提示，不执行、不上传；这里不等同保存原 ZIP 的全部内容，也不构成通用 Skill 沙箱。

实际验证来源为 [paper-framework-figure-studio-pro](https://github.com/c-narcissus/paper-framework-figure-studio-pro)，提交 `77557418b4ca8c24fa8961206bf9b8f7f6d030e1`，选择 v3.2.15f：59120 字符说明、120 个参考文字文件、33 个脚本和 3987 个素材。其绘图阶段依赖图片生成 / 参考图和脚本，当前只可讨论材料、文字步骤和方案，不能声称完整绘图工作流已跑通。未复制此包进入仓库。

导入限制：ZIP 32 MiB，8000 文件、100 MiB 声明解压总量、900000 字节参考文字，单个控制说明120000字符。拒绝绝对路径、路径穿越、重复 / 歧义根目录、链接逃逸、无效 UTF-8 / YAML；不执行下载的脚本。
