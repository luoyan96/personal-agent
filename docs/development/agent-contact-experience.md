# Agent 联系人、添加与外部接入

## 产品逻辑

人与 Agent 共用通讯录、名片、私聊和群聊。Agent 的身份 ID 保持稳定，名称、介绍、能力、性格可以修改。能力描述是公开资料，不是工具已经运行的证明；记忆与实际运行权限分别授权。

个人助理是默认置顶的自然聊天入口。创建专属 Agent 后，它进入本人通讯录并打开自己的稳定私聊；需求编排仍在可选协作中，不要求普通聊天填写任务表单。

## 三种添加方式

| 用户已有的东西 | 入口及结果 | 运行方式 |
| --- | --- | --- |
| 平台上的真人或 Agent | 准确用户名或稳定名片链接；查看资料、申请、对方同意后聊天 | 同一个身份，不复制另一个联系人的私有资料 |
| 一份 Agent 人设资料 | 导入 research-agent-profile/v1 的四项公开资料；创建或复用本人专属 Agent | 本人的平台模型；不迁移远端工具、Key、记忆或服务 |
| 外部运行的 Agent 服务 | 配置支持的 HTTPS Chat Completions 接口、模型与 Bearer Key；显式测试连接 | 真实调用外部服务；配置者承担该外部账号费用 |

手动创建可使用已有科研角色预设或填写公开资料。创建和导入后的 IM 未就绪时，重试打开已经保存的聊天，不能重复创建联系人。

## 外部服务第一版范围

协议使用 OpenAI-compatible Chat Completions 消息格式，并不代表绑定 OpenAI 服务。只接受 HTTPS 443 的公开地址，固定接口路径以 /chat/completions 结尾。任意本地 Agent、MCP 或 A2A 服务不会自动兼容；需要相应适配器。

仅发送当前这一条经发送者明确同意的文字。不会自动传出历史、私人记忆、文件、档案、任务、内部身份或 SDK 元数据。每条发送重新确认；默认只有配置所有者可调用，向已接受联系人共享调用额度需要所有者明确开启。

“已配置”与实际连接探测结果分开。探测只发送合成短文本，由所有者承担外部服务费用；失败、超时及结果不确定不会触发自动第二次调用。外部回复只作为经校验的文字，返回的工具调用不会执行。外部停用或不可用时，明确提示，不自动切换到平台模型。

默认 4000 总 token / 90 秒限制保持。服务校验公开 DNS、固定连接 IP 并检查原主机 TLS；禁止重定向、环境代理、URL 凭据与私网地址。Key 加密保存，读取只返回 hasApiKey，公开名片只显示服务 origin。

## 界面原则

- 通讯录先显示真实联系人。添加朋友、创建 Agent 和接入已有 Agent 的入口各自说明实际结果。
- 名片链接打开资料，不自动加好友、建群或发送；未登录访客登录后仍回到该名片。
- 桌面聊天直接显示已实现的表情、图片、文件、语音工具；手机使用加号展开。
- 表情只插入当前草稿。文件和录音沿用原 SDK 投递及切换会话 / 账号的异步守卫。
- 资料导入不代表能力已经接通；连接探测不代表工具执行或科研结论准确性已验证。

## 协议及交接

冻结共享契约 0.17 / chat 1.6 见 [外部接入契约](../../packages/contracts/agent-connection-protocol.md)。迁移 017 只新增私有绑定表，旧账号、联系人、消息和用量保留。schema16 代码不能直接启动 schema17 数据库；部署恢复需保留新用户记录并使用明确验证过的兼容恢复镜像，不能恢复旧数据库覆盖后续聊天。

本批实际源码、共享检查、客户端检查、合成外部服务证据与线上状态，在完成时记录到 [current-state](../current-state.md) 和 [project-log](../project-log.md)。协议参考：[Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)、[A2A 1.0](https://a2a-protocol.org/v1.0.0/specification)；本批不宣称 A2A 已实现。
