## 用户确定的产品

每位用户固定找自己的个人智能体提需求。界面类似微信：会话列表、聊天区、通讯录；个人智能体固定在顶部。任务需要协作时，助理组织一个包含真人与 AI 的任务群。用户在群内通过 @成员 完成布置、调整和查看成果。人与 agent 共用通讯录、搜索、私聊、邀请和 @入口，并明确身份及 agent 主人。科研是任务与能力匹配平台的首个落地场景。

## 本批真实闭环

1. 登录后默认打开自己的个人智能体私聊；已有消息刷新、退出再登录和重启后可找回。
2. 通讯录统一呈现实验室可见真人、与本人关联的个人 agent 和可用的公共专业 agent。显示身份、归属和可用状态。本人私聊和记忆仅对本人可见。
3. 用户消息先持久化，再触发后台 AI 工作。使用现有实验室 DeepSeek 配置；缺 Key、未启用、失败和中断必须显示真实状态，保留输入和历史，不能伪造助理回复。
4. 助理基于获准的会话/任务上下文提出任务群与分工。需要创建、邀请或执行的回复使用受控动作及服务回执；必要确认在聊天内完成。真实人加入是邀请，接受前不能假装承诺；其他人的个人 agent 需由主人授权，不能自动转移私人上下文。
5. 任务群持久化，共享目标和获准材料。@对象由联系人 ID 明确绑定，不能只靠名字字符串。对 AI 的任务进入后台执行；对真人的任务保留真实邀请、接受和交付状态。自然聊天不能自动派发或触发所有 agent 相互回复。
6. AI 至少复用一个已经接通的公共文本能力，成果与任务/版本关联，在群里查看。运行离开浏览器后继续，失败、取消、重启行为真实可追踪。尚未接通的能力显示不可用。
7. 现有任务权限、交付版本、验收、文件访问、幂等与撤权保护作为权威业务服务复用。聊天消息本身不证明工作完成。

本批先验证上述最小闭环。语音视频、朋友圈、支付、接管微信账号、任意浏览器/终端执行、无限自治循环及跨实验室能力市场另行规划。独立个人 agent 的完整外部工具生态并非本批完成声明。

## 共同验收

- A 账号看不到 B 的个人助理会话/记忆；换账号不会保留旧输入或私人历史。
- 真实多会话持久化和消息去重；同一次点击/重试不产生重复群、邀请或执行。
- 私聊创建群建议、确认建立、@真人等待本人承接、@AI后台运行、群内查看成果形成服务闭环。
- 非成员、撤权成员及未加入的 agent 无法读取群材料或执行任务。
- 私聊上下文不因建群完整复制；分享范围在确认动作内明确。
- 缺模型配置、离线、权限失效和失败有可见且准确的反馈；没有演示回复或固定成功状态。
- 浏览器验证桌面会话布局、320/390px 窄屏、键盘发送与输入法、@选择与退出/重登。
- 整合版本运行根 CI，并独立验证上述用户流程。CI 或合成模型不替代真实 DeepSeek 调用；部署另行安排。
