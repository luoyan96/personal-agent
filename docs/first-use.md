# 完成第一项协作

## 科研微信：联系人与需求对话

以下联系人新功能适用于契约 0.12.0 的本地整合版本；正式网站仍以[部署记录](deployment/ecs.md)中的版本为准。

登录后默认打开置顶的 **“需求与协作”**，下方显示你的协调 Agent 的真实名字。把目标、材料和交付要求发给它，核对它提出的任务群与分工后确认。其他 Agent 的私聊按各自的设定回复；在任务群中选择或 @ 对应成员继续协作。

- **找人与 Agent**：打开“通讯录”，在“我的联系人”或“发现”中选一位，查看身份、介绍、能力和可用状态。添加真人需对方同意；添加他人的私人 Agent 需其负责人同意。在“请求”中处理申请，“全部记录”可查看已同意记录并撤销添加授权。添加联系人、加入任务群和接受任务各自确认。
- **设置自己的资料**：点击左栏“我的资料”。Agent 负责人可以在其联系人详情中编辑名字、介绍、能力介绍和性格；这些设定不会增加工具或材料访问权限。
- **创建自己的 Agent**：点击通讯录中的“创建 Agent”，填写上述设定后保存。它会成为具有稳定身份的专属联系人，使用本实验室已配置的模型；模型未启用时会显示实际不可用状态。
- **保存记忆**：在本人 Agent 详情中打开“私有记忆”，明确填写内容和来源后保存，可编辑、移除及检查保存记录。它只用于你自己的相关 Agent 对话。聊天中的“会话共同记忆”只属于当前会话，其他会话不会自动得到它；维护权限以页面显示为准。当前记忆由用户主动保存，聊天文本不会自动变成长期记忆。

撤销添加授权会停止相应私聊的读取与发送；任务群和任务承诺仍各自管理。重新添加须再次同意。下面保留账号、模型配置和任务交付指引。

## 账号与实验室设置

**第一次来**：在登录页选择“使用邀请码注册”，填写实验室负责人提供的邀请码、账号、显示名及两次密码（超过 8 个字符）。注册成功后登录；账号区分大小写。邀请码决定你加入哪个实验室，不会让你自动获得他人任务材料。邀请码失效或名额已满时向负责人索取新的邀请码；已有账号直接登录。

**实验室负责人首次注册**：使用维护者单独交付的单次负责人开通码注册，并自行设置账号和密码。登录后进入“实验室设置”，点击“管理邀请码”；在此选择有效天数和可注册人数，创建成员邀请码。原码只在创建成功的当前页面显示，请当场复制并交给受邀成员；之后列表只显示编号、状态、名额及到期时间，可撤销未用完的邀请码。普通成员没有此入口，也不能通过管理接口签发邀请码。

**实验室负责人配置 AI**：登录后进入“实验室设置”，选择 DeepSeek 模型，在网页上输入本实验室的 API Key，勾选“启用本实验室的大模型调用”并保存。Key 保存后不再显示原文；不要发到聊天中。仅保存设置不会调用模型或产生费用，首次调用请用获准的合成需求从“需求入口”发送并检查结果。需要停用时在同一页取消勾选并保存；也可明确删除已保存的 Key。平台总开关尚未开放时，页面会提示暂不可启用。

登录后从需求入口开始。页面内的“第一次使用或遇到问题？”可展开同样的短指引；登录页也可打开 `#/help`，断开服务时仍能阅读。

## 任务交付与验收

1. **提出需求**：写目标、材料与交付要求，发送给 AI，或选择“手工创建方案”。AI 未配置时仍可手工安排。
2. **核对方案与日期**：检查分工、邀请对象、交付和验收要求。建议日期不是承诺，硬性截止需核实，未知时间可以留空。先保存，再确认此版本并安排；只保存不会派发。
3. **回应与开始**：受邀人从入口的本人待处理进入任务，接受或拒绝；开放任务按权限认领。接受后核对承诺，在任务中开始。依赖未满足时先处理阻塞。
4. **提交成果**：在任务内填写文本，按需上传附件，上传成功后才引用。不要求披露私人工具、方法或过程日志。公共能力的候选需核对后明确提交，运行成功不等于验收。
5. **人工验收**：验收人核对交付版本，接受或退回并说明原因；承接人修改后重新提交。验收不要求共享反馈或私人方法。

**离开后继续**：重新登录，从入口找本人生成请求（包括排队、失败）、已保存草案、我参与的任务。后台运行在原任务内查看。关闭页面不取消后台工作；未保存的本地输入不能跨浏览器恢复。

**保留与复用结论**：在任务/验收上下文展开“保留结论”，核对内容、来源版本、适用和共享范围，明确确认。新生成请求或任务运行中主动勾选获准结论；未选不自动复用。来源过时、撤回或无权时先处理提示。

**撤回本人样例**：进入原任务，展开“我在此任务的样例授权”，填写原因并撤回；无需公共方法维护权限。撤回停止后续使用，无法追回已下载副本。

| 遇到什么 | 下一步 |
| --- | --- |
| AI 未配置或公共能力不可用 | 继续手工安排/人工交付。若提示“上一请求未确认”，先重试或明确“放弃原请求”；模型未启用而拒绝的请求可直接改走手工路径。放弃本地未决请求不等于取消服务已接受的运行。 |
| 材料不支持 | 当前公共文本能力使用获准的 UTF-8 纯文本，不识别 PDF/图片；按能力说明准备材料或人工交付。 |
| 服务断开 | 恢复连接后读取最新状态；未决操作重试同一请求，沿用原内容。整体服务不可用时手工协作也需等待恢复。 |
| 会话失效 | 同账号重新登录可继续本标签页保留的输入/原请求；重置后用新密码。账号停用联系管理员。主动退出/换账号会清空本地输入。 |
| 冲突或权限变化 | 读取最新状态并比较，再明确确认新意图；无权的旧内容会清除。 |
| 运行中断 | 读取最新状态，仅按服务允许的操作继续；结果或用量未知时联系维护者，不反复新建来猜测结果。 |

**维护者负责**账号开通/重置/停用、服务与 worker、平台模型总开关/公共能力配置、未知用量和备份恢复；实验室负责人管理本实验室的模型 Key 和启停。普通成员不用学习部署细节。求助时提供发生的操作与折叠的请求编号，不发送密码或私有材料。
